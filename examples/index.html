Variants

Three Notebook surfaces sharing one skeleton. Open each in a separate tab to compare; swap the body class between -dark and -light in the source to flip mode.

VA · va-dark / va-light

Bound notebook

Cocoa paper, bone ink, sunset oxblood. The contemplative default. Used by hysres/web. VB · vb-dark / vb-light

Engineer's graph pad

Graph-paper substrate, blueprint blue, red caution. For measurement displays and technical readouts. VC · vc-dark / vc-light

Archive card

Paper card mounted on felted substrate, deep oxblood + ochre. For indexed material, catalog entries, archival notes.

Shared skeleton: Newsreader serif (Latin) + Noto Serif SC (CJK) + JetBrains Mono labels + 8-pt grid + B-H curve mark. Each example file is self-contained — open in a browser or copy as a starting point.
