# Hysteresis Research · brand book

Normative brand reference shipped with [`@hysres/tokens`](README.md).
Voice rules derive from the firm's founding document and blurb,
held in the internal firm-operations repo.

```
@hysres/tokens/
├── README.md                   npm install / usage
├── BRAND.md                    this file · brand book
├── tokens.css                  design tokens · 3 variants × 2 modes
├── assets/
│   ├── bh-mark.svg             master mark · currentColor · scales 1.4-3.0
│   ├── stamp.svg               corner-stamp variant · stroke 2.6
│   ├── favicon.svg             auto-theme favicon · prefers-color-scheme · square
│   ├── wordmark.svg            mark + EN wordmark · horizontal lockup
│   └── wordmark-bilingual.svg  mark + EN + CN 迟 滞 研 究 lockup
└── examples/
    ├── index.html              full-surface specimen
    ├── variant-a.html          A · Bound notebook
    ├── variant-b.html          B · Engineer's pad
    ├── variant-c.html          C · Archive card
    └── lockup.html             cross-variant lockup + palette reference
```

PNG favicon exports (16 / 32 / 192 / 512 / apple-touch 180) are
generated by downstream consumers (e.g. `hysres/web` public/) from
`assets/favicon.svg` via `sips -s format png -Z <size>`.

The brand mark is a **magnetic hysteresis loop** (B-H curve). The
shape literally embodies the firm's edge thesis: as the field cycles,
magnetisation lags — the enclosed area is the energy lost per cycle.

## Voice

Austere. Bilingual where it counts. Refuses to sell.

- **"long enough to be measured"** — the **signature phrase**. Never
  paraphrase. Always set in serif body weight, never in chrome.
- **"Research compounds; capital follows."** — the **closing
  aphorism**. Italic, smaller, always at the bottom of a document.
  Never used as a thesis statement.
- **No "research firm" as noun.** Always "research-driven … trading
  firm".
- **No enumeration of techniques in public copy.** β symmetry test,
  formalised Wyckoff, kill conditions etc. belong in the working
  memo, not the LP letter or firm site.
- **No defensive statements.** Values priority lives in the founding
  doc, not in public copy.
- **"We"** in public, never "I". "The firm" / "the desk" in working
  memo third person.
- **EN-only by default.** CN appears on the business card, LP letter,
  and founding documents — `迟 滞 研 究` with `letter-spacing: 0.32em`.

### No emoji. No icon library.

Only typographic primitives:

```
→ ↑ ↓ ← ⟶         flow arrows
· — ─             separators
§                 section sign
◯ ● ◎             status markers · open / fired / target
β σ μ ρ           Greek for technical quantities
═══ ───           ASCII box rules in working documents
```

## Typography

| Role | Family | Weights | Source |
|---|---|---|---|
| Display + body | **Newsreader** | 400 / 500 / 600 + italic, opsz 6-72 | Google Fonts |
| Chrome / mono | **JetBrains Mono** | 400 / 500 (tabular nums) | Google Fonts |
| CJK fallback | **Noto Serif SC** | 400 / 500 / 600 | Google Fonts |

Newsreader has no CN glyphs. `tokens.css` registers a `Newsreader CJK`
`@font-face` with `unicode-range: U+4E00-9FFF, U+3000-303F, U+FF00-FFEF,
U+2E80-2EFF, U+3400-4DBF` so Noto Serif SC only shadows Newsreader on
CJK characters.

**No system stacks.** This system explicitly does not use `-apple-system`,
SF Pro, or Helvetica — they belong to other firms.

Tracking:
- Display headlines: `-0.014em` (Newsreader's metric tuning)
- Italic body: `+0.005em`
- Mono labels: `+0.04em` to `+0.22em` depending on size
- CN lockup: `0.32em` when small, `0.08em` when large

## Colour · per variant

Each variant has its own substrate + accent family. All defined in
[`tokens.css`](tokens.css). Foreground tiers always `--ink` / `--ink-2`
/ `--ink-3`. Change the mode, the same vars rebind.

| | Dark substrate | Light substrate | Accent (dark) | Accent (light) |
|---|---|---|---|---|
| **A · Bound notebook** | `#181410` cocoa | `#f3efe4` cream | `#d97c5e` sunset | `#6e2c1f` oxblood |
| **B · Engineer's pad** | `#0a0c10` near-black | `#eeece4` cool bone | `#7ec5ff` cyan | `#1b5fa6` blueprint blue |
| **C · Archive card** | `#14130f` ink | `#d4cdb8` dust | `#d97c4a` terracotta | `#883a23` deep oxblood |

**No purple. No gradient. No glow. No saturated greens or blues
except B's blueprint accent.** Mode toggling happens via a class on
`<body>` (`va-dark`, `va-light`, etc.), persisted to `localStorage`.

### Print · CMYK approximations

⚠️ **Approximate values only — verify with your printer's colour
profile and paper.** sRGB-to-CMYK conversion depends on paper, ink,
and press; the values below come from a generic
SWOP/Coated-v2 profile and will shift on press.

| Hex | CMYK (approx, generic coated) | Notes |
|---|---|---|
| `#d97c5e` A · sunset oxblood | C 0 / M 56 / Y 64 / K 7 | will shift warmer on uncoated stock |
| `#6e2c1f` A · oxblood (light) | C 27 / M 87 / Y 92 / K 30 | strong on press; verify trap |
| `#d97c4a` C · terracotta | C 0 / M 56 / Y 80 / K 7 | similar gamut to A's sunset |
| `#883a23` C · deep oxblood | C 27 / M 86 / Y 96 / K 28 | richer red than A oxblood |
| `#1b5fa6` B · blueprint blue | C 84 / M 56 / Y 0 / K 18 | watch CMYK gamut limits |
| `#7ec5ff` B · cyan blueprint | C 50 / M 19 / Y 0 / K 0 | screen-only; cannot print accurately |
| `#181410` A · paper dark | C 60 / M 65 / Y 75 / K 90 | rich black; print as K100 if simpler |
| `#f3efe4` A · paper light | C 3 / M 4 / Y 10 / K 0 | warm white; verify on uncoated |

Workflow: when sending to print, hand the printer this README, the
hex values, and ask for **press-calibrated CMYK** for the specific
stock and process. Treat the values above as a starting point.

## The B-H mark

| File | Use | Stroke (at 100×60) |
|---|---|---|
| `bh-mark.svg` | master · inline beside wordmark, chart headers, slide masters | 2.4 default |
| `stamp.svg` | corner stamp · memo footer, business card back, LP letter signature | 2.6 |
| `favicon.svg` | browser tab · auto-theme · square 100×100 viewBox | 5 |
| `favicons/*.png` | raster export for app icons / Open Graph / print vendors | — |

All marks use `currentColor` (favicon overrides for theme); recolour
by setting the parent's `color`.

### Size scale (master)

| Pixel height | Stroke | Use |
|---|---|---|
| 28 | 1.4 | inline beside body text · email signature |
| 48 | 2.0 | header chrome · memo letterhead |
| 80 | 2.4 | hero block · slide master |
| 132 | 3.0 | firm site hero · cover slide |

It is **not** used as a chart marker, as a section divider, or scaled
larger than 200 px. Repetition would dilute it.

## Lockups

`wordmark.svg` and `wordmark-bilingual.svg` are live-text SVGs. The
text depends on Newsreader being available (web fonts or system
install).

### Before sending to a print vendor

The text in `wordmark.svg` / `wordmark-bilingual.svg` is **live**, not
outlined. Open in Inkscape:
```
File → Open → wordmark.svg
Select All → Path → Object to Path
File → Save As → wordmark-outlined.svg
```
or from the CLI:
```
brew install inkscape
inkscape wordmark.svg --export-text-to-path --export-filename=wordmark-outlined.svg
```

Outlined SVGs ship to the printer without font dependencies. For the
bilingual lockup, ensure Noto Serif SC is installed before outlining
or the CJK glyphs will be missing.

## Hard rules

1. **No purple. No gradient. No glow. No SaaS-bright accents.**
2. **Display is always Newsreader.** No Inter, no SF Pro, no
   Helvetica for headlines.
3. **All numbers are mono with `font-variant-numeric: tabular-nums`.**
4. **The B-H mark is always currentColor stroke, never fill.**
5. **The signature phrase "long enough to be measured" is single-line
   and never paraphrased.**
6. **No emoji. No icon library.** Only unicode primitives and the
   B-H mark.
7. **No "research firm" as noun.** Always "research-driven … trading
   firm".
8. **CN is reserved for business card + LP letter + founding docs.**
   The firm site, memo, infographic, and other working surfaces are
   EN-only.
9. **Square corners by default.** Radii 0-2px. Pill only on the
   7×7 status indicator dot.
10. **Mode swap is instant.** No transition on color regime changes.

| Variant | Substrate | Owns |
|---|---|---|
| **A · Bound notebook** | cocoa / cream paper | firm site, working memo, letterhead, founding doc |
| **B · Engineer's pad** | near-black / bone with blueprint grid | analytical infographics, drawdown / cycle / IV-surface plots |

For decks: mix **C** (cover, dividers, closing quote) with **B**
(data slides). A is reserved for prose-dense surfaces (firm site,
memo); slides amplify A's density problem.

## Open caveats

- **Newsreader CN fallback** loads Noto Serif SC via Google Fonts at
  runtime. For full offline / print, self-host the Noto Serif SC
  woff2 files in your consumer repo and override the `@font-face`
  `src` to point at the local files.
- **Wordmark SVG text is live** — outline before sending to print
  (see "Before sending to a print vendor" above).
- **CMYK values are approximations.** Always verify with the print
  shop using their colour profile before final approval.
- **Favicon dark-mode is OS-level**, not site-mode. On a dark-mode
  desktop, the favicon strokes light ink even if the page is in
  Variant C light. This is intentional — the favicon belongs to the
  browser, not the surface.
- **The brand mark is a pure SVG path.** No raster logotype exists;
  if a vendor demands raster, generate from `assets/bh-mark.svg` at
  the required size via `sips -s format png -Z <size> assets/bh-mark.svg`.

## Quick reference

Mode classes — apply to `<body>`:

```html
<body class="va-dark">    <!-- A · Bound notebook, dark (default) -->
<body class="va-light">   <!-- A · Bound notebook, light -->
<body class="vb-dark">    <!-- B · Engineer's pad, dark -->
<body class="vb-light">   <!-- B · Engineer's pad, light -->
<body class="vc-dark">    <!-- C · Archive card, dark -->
<body class="vc-light">   <!-- C · Archive card, light -->
```

Inline mark — drop anywhere, recolour via parent:

```html
<svg width="48" height="29" viewBox="0 0 100 60" aria-hidden="true">
  <path d="M 10 54 C 30 54, 38 53, 58 30 C 70 13, 78 7, 90 6
           C 70 6, 62 7, 42 30 C 30 47, 22 53, 10 54 Z"
        fill="none" stroke="currentColor" stroke-width="2.4"
        stroke-linecap="round" stroke-linejoin="round"/>
</svg>
```

Favicon link (consumer's `<head>` — paths assume `assets/favicon.svg`
and PNG exports were copied to the public root):

```html
<link rel="icon" type="image/svg+xml" href="/favicon.svg">
<link rel="alternate icon" type="image/png" sizes="32x32" href="/favicon-32.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
```

In Next.js App Router, prefer the `metadata.icons` API instead:

```ts
// src/app/layout.tsx
export const metadata: Metadata = {
  icons: {
    icon: [
      { url: '/favicon.svg', type: 'image/svg+xml' },
      { url: '/favicon-32.png', sizes: '32x32', type: 'image/png' },
      { url: '/favicon-192.png', sizes: '192x192', type: 'image/png' },
    ],
    apple: { url: '/apple-touch-icon.png', sizes: '180x180' },
  },
};
```
